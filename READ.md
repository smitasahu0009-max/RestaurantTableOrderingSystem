# 🍴 Restaurant Table Ordering System

A Java Swing based restaurant table ordering system connected with MySQL using JDBC.

## 🚀 Features

- Table number based ordering
- Menu loaded from MySQL database
- Item and quantity selection
- Automatic bill calculation
- Order placement
- View all orders
- Delete orders
- Order status management
- Pending → Preparing → Served
- MySQL database integration using JDBC

## 🛠️ Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- Maven
- IntelliJ IDEA

## 🗄️ Database

Database name:

`restaurant_db`

Main tables:

- `menu`
- `orders`

## ▶️ How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Make sure MySQL is running.
4. Create the `restaurant_db` database and required tables.
5. Configure the database connection.
6. Run `RestaurantGUI.java`.
